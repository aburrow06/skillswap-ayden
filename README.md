# SkillSwap

SkillSwap is a responsive homepage concept for a community platform where people can discover skills, learn from others, and offer their own knowledge. The homepage includes a hero section, navigation, popular skill cards, category filters, expandable session details, and a call to action for new skill providers.

## Technologies

- HTML5 with semantic page structure
- CSS3, including responsive layouts, Flexbox, and CSS Grid
- Vanilla JavaScript for category filtering and interactive skill cards
- Git and GitHub for version control and pull-request workflow

## Run locally

Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.

## Project notes

The skill listings and provider names are sample content for this frontend prototype. The contact link is a placeholder and does not submit a real provider application.
